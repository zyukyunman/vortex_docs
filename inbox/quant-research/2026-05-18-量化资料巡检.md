## 1. PRISM-VQ 离散潜在因子 + 金融先验

- 标题：[Vector-Quantized Discrete Latent Factors Meet Financial Priors: Dynamic Cross-Sectional Stock Ranking Prediction for Portfolio Construction](https://arxiv.org/abs/2605.13407)
- 作者/机构：Namhyoung Kim、Jae Wook Song。
- 日期：arXiv v1 2026-05-13；IJCAI 2026 accepted。
- 来源类型：arXiv，cs.LG / q-fin.ST。
- 核心问题：传统因子模型可解释但不够灵活，深度模型灵活但容易忽略金融先验，如何把先验因子、离散潜在因子和动态加载结合起来做横截面排序。
- 机制：PRISM-VQ 用 vector quantization 把横截面结构压缩成离散 codes，再把这些 codes 作为 latent factors 与 MoE routing 信号，生成随市场结构变化的 factor loadings。
- 证据：摘要显示在 CSI 300 和 S&P 500 上相对强基线提升预测和组合表现，并提供代码链接；本轮仍是摘要级核验，未审代码、数据切分和成本口径。
- A 股迁移问题：CSI 300 结果贴近 A 股，但本地若复现，必须先决定它是“模型研究 seed”还是“因子发现方法论”，不能直接变成交易策略。
- PIT/过拟合风险：最大风险是训练窗口、特征标准化和组合标签泄漏；VQ codes 可能只是样本内 regime 标签，必须做滚动切分、block/CPCV 和负对照。
- 初筛评分：16/18。

## 2. Transient statistical factors 风险模型增强

- 标题：[Enhancing a Risk Model by Adding Transient Statistical Factors](https://arxiv.org/abs/2605.12977)
- 作者/机构：Alexandros E. Tzikas、Emmanuel J. Candès、Trevor Hastie、Stephen P. Boyd、Mykel J. Kochenderfer、Ronald N. Kahn。
- 日期：arXiv v1 2026-05-13。
- 来源类型：arXiv，stat.AP / q-fin.MF / q-fin.RM / q-fin.ST。
- 核心问题：第三方风险模型可能漏掉 transient factors 和 regime change，如何只用 realized returns 系统性增强既有 factor model。
- 机制：在已有风险模型上用 maximum likelihood 同时 refine 原模型并新增统计因子；只依赖收益序列、额外因子数和 half-life 两个关键超参。
- 证据：摘要显示作者在 Barra short-term US risk model 和美国大盘股宇宙上演示，可捕捉原模型遗漏结构；未见 A 股实证。
- A 股迁移问题：更适合做 Vortex 的 risk/exposure review 工具，而不是 alpha。可用于检查某个候选因子是否只是短期共同风险结构。
- PIT/过拟合风险：half-life、因子数和缺失处理都可能样本内调优；如果把 transient factor 当 alpha，容易把风险共振误当可交易收益。
- 初筛评分：13/18。

## 3. Slope, Strength, and Retail Extrapolation

- 标题：[Slope, Strength, and Retail Extrapolation](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=6731259)
- 作者/机构：Chad Schmerling。
- 日期：SSRN posted 2026-05-07。
- 来源类型：SSRN 工作论文。
- 核心问题：投资者是否在形成收益预期时使用趋势斜率和趋势平滑度，而传统动量忽略了路径形态。
- 机制：摘要页显示其关注 trend smoothness、OLS trend filter、center-weighted trend、visual extrapolation、retail investors、momentum 和 PEAD。
- 证据：本轮网页抓取 SSRN 正文被 403 阻断，只完成搜索结果级核验；需要下轮 digest 前重新打开 PDF 或人工下载。
- A 股迁移问题：A 股散户占比高，路径平滑度和视觉趋势外推可能比美股更强。可用日收益序列构造斜率、R2、中心加权趋势和公告后 drift 的交互项。
- PIT/过拟合风险：趋势形态类因子参数空间大，容易变成形态挖掘；必须固定窗口和形态定义，先用 minimum falsification test 与普通 momentum/short reversal 对比。
- 初筛评分：14/18。

## 4. DRIF: daily return information factor

- 标题：[A Unified Framework for Anomalies based on Daily Returns](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=6005614)
- 作者/机构：Nusret Cakici、Christian Fieberg、Gabor Neszveda、Robert J. Bianchi、Adam Zaremba。
- 日期：2026-01-02。
- 来源类型：SSRN 工作论文。
- 核心问题：许多横截面异象是否都来自上月日收益序列中的同一类信息。
- 机制：用 data-driven 方法从过去一个月 daily return distribution 到未来收益建立经验映射，形成 Daily Return Information Factor。
- 证据：摘要称 DRIF 在子样本和多种 research design 下成立，并在控制 modern factor zoo 后仍显著；需读正文确认 elastic-net、特征工程和成本。
- A 股迁移问题：高度贴近本地短反、PRV、tail-risk、量峰/量谷和日频路径类因子。优先价值在于做重复度审查，不一定是新 alpha。
- PIT/过拟合风险：如果用日收益分布自由生成大量特征，很容易多重检验；必须以父代因子和负对照为基准，先问它是否只是更复杂的短反。
- 初筛评分：15/18。

## 5. Revaluation Alpha

- 标题：[Revaluation Alpha](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=5451754)
- 作者/机构：Robert D. Arnott、Sina Ehsani、Campbell R. Harvey、Omid Shakernia；Research Affiliates、Northern Illinois University、Duke / NBER。
- 日期：Date Written 2025-09-06；SSRN posted 2025-09-08。
- 来源类型：SSRN 工作论文。
- 核心问题：历史因子收益中有多少来自估值倍数重估，多少是真正结构性 alpha。
- 机制：把因子历史收益拆成 revaluation return 与 structural return；估值扩张带来的收益不能无限外推，甚至可能均值回归。
- 证据：摘要称 structural return 比 raw historical return 更能预测未来因子收益，并且在 momentum 等择时信号之外有增量。
- A 股迁移问题：适合作为“因子层择时”线索：对本地已有因子，拆解因子组合估值扩张与结构性收益，再决定是否继续研究。
- PIT/过拟合风险：因子估值口径必须在时点可得；不能用全样本 winner 因子再做 revaluation 拆解。
- 初筛评分：13/18。

## 6. Corporate Bond Factor Replication Crisis

- 标题：[The Corporate Bond Factor Replication Crisis](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=6088966)
- 作者/机构：Alexander Dickerson、Cesare Robotti、Giulio Rossetti；UNSW、Warwick。
- 日期：Date Written 2026-01-18；last revised 2026-04-09。
- 来源类型：SSRN 工作论文。
- 核心问题：公司债因子动物园中多少收益来自真实风险溢价，多少来自数据和交易价格偏差。
- 机制：作者指出 OTC microstructure 会导致 signal-formation price 与可成交价格不一致，ex-post filtering 会把未来信息嵌入因子构建。
- 证据：摘要称他们构建 Open Bond Asset Pricing 管线，并对 108 个 signals 做 bias correction 后发现多数异象失败。
- A 股迁移问题：虽然是公司债，但对 A 股同样有警示：停牌、涨跌停、ST、复权、成交约束和 ex-post universe/filter 都可能制造假因子。
- PIT/过拟合风险：这是本轮最强的风险方法论资料之一，适合沉淀成 quality gate 反例，而不是生成新因子。
- 初筛评分：12/18。

## 7. AQR Momentum Indices, Monthly

- 标题：[AQR Momentum Indices, Monthly](https://www.aqr.com/Insights/Datasets/Momentum-Indices-Monthly)
- 作者/机构：AQR。
- 日期：2026-04-30。
- 来源类型：AQR dataset / method page。
- 核心问题：如何用简单透明的规则捕捉股票动量。
- 机制：页面说明其以过去 12 个月总收益排序并排除最近 1 个月，筛选流动性与市值后取最高排名 33%，按市值权重，季度再平衡。
- 证据：这是指数方法入口，不是新论文；适合作为标准动量控制项和实现口径参照。
- A 股迁移问题：可用于本地动量/路径形态研究的 baseline，不应与更复杂的图像识别、DRIF 或 slope-strength 因子混淆。
- PIT/过拟合风险：指数表现不含真实管理费、交易成本和组合差异；A 股迁移还要考虑涨跌停、停牌、ST、调仓成交和小票容量。
- 初筛评分：11/18。
