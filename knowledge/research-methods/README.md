# 研究方法知识

- 研究假设如何产生。
- 如何设计最小可证伪实验。
- 如何判断样本外、过拟合和数据泄漏。
- 如何阅读因子、事件驱动、组合构建相关论文。

这个目录只沉淀方法和判断框架，不写生产回测代码。
