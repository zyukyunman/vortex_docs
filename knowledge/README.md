# 知识库总览

这里放整理后的知识，而不是原始材料。

建议按主题建立子目录：

- [[量化系统知识]]：研究平台、回测可信度、MLOps、Harness、执行系统语境。
- [[资产配置知识]]：资产配置、永久组合、风险平价、趋势跟随等。
- [[AI模型知识]]：金融时间序列建模、特征/标签、模型训练与评估。
- [[研究方法知识]]：论文方法论、因子假设来源、实验设计。

每篇笔记应尽量说明来源、机制、证据、限制和下一步，而不是只做摘抄。
