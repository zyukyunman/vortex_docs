# 量化研究学习知识库

这是一个独立的量化研究学习仓库。它的角色不是写策略代码，而是作为你的知识系统：读论文、读书、拆解专业文章、形成研究假设、评估可行性，并在必要时沉淀成可以被智能体调用的本地技能。

它和 `../vortex_quant` 的关系是上下游关系：

- `vortex_docs`：书籍、论文、研报、文章、访谈和网页材料等外部输入；探索性机制、假设来源和开放问题。
- `vortex_quant`：产品、架构、代码功能、用户手册、因子研究、策略研究、回测、执行和实盘相关内容。

归属细则见 [[仓库定位与边界]]。一条内容只要开始使用 Vortex 本地数据、runner、artifact、preset 或交易链路，就应该回到 `vortex_quant/docs` 沉淀。

## 目录

- `AGENTS.md`：本仓库的智能体行为边界和 Context7 文档查询规则。
- `.codex/skills/`：本仓库专用的研究阅读、知识沉淀和技能生成流程。
- [[知识库结构总览]]：仓库定位、沉淀流程和知识地图。
- [[待处理材料入口]]：后续你给的文章、链接、临时摘录和待整理材料入口。
- [[原始资料库]]：书籍、论文、长报告等原始资料。
- [[知识库总览]]：整理后的知识卡、主题笔记和可行性备忘录。
- [[历史材料]]：低频参考材料，目前主要是职业定位材料。

## 当前整理结果

已有材料被拆成三类：

- [[量化系统知识]]：CPCV、Harness、MLOps/DevOps 等量化系统语境补课。
- [[职业材料]]：AI 量化系统开发职业定位、项目故事、面试问答、公司研究。
- [[书籍库]]：现有书籍 PDF。

## 后续使用方式

当你给一篇文章、一本书或一个研究方向时，我会优先在这个仓库里完成：

1. 放入 `inbox/` 或引用原始来源。
2. 生成阅读笔记或主题知识卡。
3. 判断它更像研究假设、系统方法、AI 模型训练方法、非代码绑定投资框架，还是职业/行业认知材料。
4. 如果它会反复使用，再沉淀为 `.codex/skills/` 里的本地技能。
5. 如果后续要在 `vortex_quant` 里验证，只保留来源路径、机制和检查项；具体因子研究、策略结论和代码绑定投资框架在 `vortex_quant/docs` 中维护。
